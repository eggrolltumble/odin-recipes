# Odin Recipes

A recipe website built with HTML as part of The Odin Project's Foundations course.

## About

This project is a simple multi-page site with a home page that links to individual recipe pages.

## Skills demonstrated

- Writing HTML boilerplate and structuring a page
- Using headings, paragraphs, and lists
- Linking between pages with relative links
- Adding images
- Using Git and GitHub: creating a repo, cloning over SSH, committing, and pushing
